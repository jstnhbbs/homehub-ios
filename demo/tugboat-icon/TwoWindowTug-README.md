# Two-Window Tugboat Concept

Open `TwoWindowTug.icon` in Icon Composer. It is a standalone concept and is not wired into the app target.

The seven editable SVG layers are in `TwoWindowTug.icon/Assets`. Each uses a shared 1024 x 1024 canvas, so importing them without resizing keeps their alignment. The cream background is the document fill, not a rounded rectangle; Icon Composer supplies the platform mask.

The document lists frontmost layers first. When assembling manually, the back-to-front order is Wave, Rear Bulwark, Smokestack, Smokestack Band, Cabin, Hull, Cabin Windows. Set the background to #FBF5E6. Specular/glass and translucency are disabled to preserve the drawn colors.

This is an editable vector recreation of the brainstorm image, not an automatic pixel-for-pixel trace. Two broad, angled cabin windows replace the single window; the hull has no eye-like porthole.
